    Nova Notificação
    Como funciona

    Notificações são disparadas pelo serviço de sync quando o status de um cliente muda (ex: ativo → suspenso).

    Webhook — envia um HTTP POST com JSON:

    {
  "event": "status_change",
  "cliente_nome": "...",
  "cpf": "...",
  "pppoe_login": "...",
  "old_status": "ativo",
  "new_status": "suspenso"
}

    E-mail — configure as variáveis SMTP no .env: SMTP_HOST, SMTP_PORT, SMTP_USER, SMTP_PASS
